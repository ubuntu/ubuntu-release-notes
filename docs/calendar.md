# Release calendars

Follow Ubuntu release schedules in your calendar app, such as GNOME Calendar, Thunderbird, Google Calendar or Outlook. Each calendar contains the milestones of the release schedule, such as freezes, the Beta and the final release.

To receive updates when a schedule changes, copy the link to a calendar file and add it to your calendar app as a subscription. Look for an option such as *Add calendar from URL* or *Subscribe to calendar*. To add the dates only once, download the file and import it instead.


The calendars are generated from the release schedules in this documentation. To propose a change to a schedule, see {ref}`contribute-update-release-schedule`.
